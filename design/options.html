Selection: if, elif & else

Make a program choose what to do — then use it to turn an exam percentage into an IB grade.

01

Learn

4 min read · 1 example

Selection lets a program choose which instructions to run. Python checks a condition — a Boolean expression that is either True or False — and only runs the indented block underneath when it is True.

ifTest the first condition.
elif"Else if" — only checked when everything above was False.
elseRuns when no condition matched. No condition of its own.
Relational<<=>>===!=Booleanandornot
Exam tip

Order matters. Test the highest boundary first — if you check score >= 50 before score >= 70, a student with 90% gets a 5.

Boundary values like exactly 60 are an exam favourite
Example 1 is open in the editor on the right — press Run and type a score.
# score: int — exam percentage (example boundaries, not official ones)
score = int(input("Enter your score: "))

if score >= 70:
    grade = 7
elif score >= 60:
    grade = 6
elif score >= 50:
    grade = 5
else:
    grade = 4

print("IB grade:", grade)

Write grade_for(score)

Return the IB grade (4–7) for a percentage using the example boundaries. Use return, not print — the hidden tests call your function directly.

def grade_for(score):
    if score >= 70:
        return 7
    elif score > 60:
        return 6
    elif score >= 50:
        return 5
    return 4

A student enters 60. What does the example program print?

  • Correct. 60 >= 60 is True — >= includes the boundary — so line 7 runs and Python skips every elif and else below it.
