Practice question check (Skulpt)

Runs every "predict the output" program and every model solution for "write code" questions in the same Python engine the site uses, and compares the results. It also checks that every question has its reasoning: steps for multiple choice, a line-by-line run that works for output and trace questions, notes on every solution line, a diagnosis for every test (and that the solution still passes with its notes removed), and "why this earns the mark" plus a labelled model answer for written questions. Finally it runs every code block in the "Build it from scratch" notes — including every stage of each line-by-line build — and builds every notes trace table. It also checks ~6,000 float results against real Python (tools/floatfuzz.py / .out). Open via a local server: python3 tools/serve.py, then http://localhost:8765/tools/check.html?n=20.
